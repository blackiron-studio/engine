# Wisp Hollow

A 2D lantern adventure through a moonlit grove. Gather embers, evade wisps and keep the light alive.

Run `bun run dev` here, or `bun run gallery` from the engine. WASD/arrows, gamepad or touch move the lantern keeper. Hold the pointer to walk. Escape pauses, M toggles sound, and K cycles the vector keeper, rig, imported sheet and painted hero for comparison.

The upgraded example preserves the original rules, endless scoring and saved best score. Retained vector shapes provide the keeper, layered foliage, rocks, flowing path and moon shrine. Sprites, particles and shadow-casting lights remain available alongside them. The ember compass points toward the nearest collectible. Pause freezes the world and scene clock while its UI remains usable.
