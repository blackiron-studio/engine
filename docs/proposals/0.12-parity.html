The parity pass: what Godot and Unity give a 2D game, without the editor

Blackiron 0.12, 5 September 2026. Written as the record of a pass the user asked for after the 0.11 rigs: "improve the engine for now, don't focus on store plumbing and Windows, but do all the rest."

The gap list came from a straight comparison against the two engines for the games in the plan: pixel-art 2D, AI-written code, native exports. Everything below shipped in this release, in one protocol change for rendering and additions elsewhere. Store plumbing and Windows builds were set aside on purpose and remain the next two items.

The render protocol change

Vertices went from ten to twelve floats: position, texture coordinate, colour, then mode (blend plus four times the material), slot (nearest atlas, linear atlas, glyphs, procedural light, scratch target) and two parameters. One fragment shader, in GLSL for WebGL2 and WGSL for the kernel's wgpu renderer, handles every case; the scene pass writes a second colour target with normals when the atlas has any. Both kernels emit identical vertices and the parity test still holds them to it.

How the pieces prove themselves

Wisp Hollow's trees and knight carry bevel normals, its trunks occlude, and the lantern casts shadows; the goldens on the desktop host show it. The knight example flashes white when hurt. The test suite covers the ops, the atlas normals, occluder segments and the scratch pass, bus effects (in Rust), shape casts and one-way platforms, blob masks, A*, merged colliders, tileset import, crossfades, IK, skins, containers, announcements and the locale module.

Not in this pass

  • Streaming music: shipped right after, in 0.12.1, as a symphonia-based decoder in the kernel (codecs feature, audio.wasm on the web) with crossfaded loops.
  • Arbitrary shaders: the material set covers what pixel games reach for. A user shader would need one source compiled to both GLSL and WGSL; the material switch is the deliberate stand-in.
  • Skinned meshes as an import format: Skin2D takes bones in code; a JSON with weights per vertex would be a small addition.
  • Windows and Linux builds from this machine, and store plumbing: by the user's instruction, next.
Status: shipped as 0.12.0. Engine suite at 227 tests; both examples re-verified on the macOS host.
